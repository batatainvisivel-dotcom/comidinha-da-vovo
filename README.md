# Comidinha da Vovó 🍽️

Site profissional para restaurante de comida caseira em Goiânia.

## 🌟 Características

✅ **Design Responsivo** - Funciona perfeitamente em desktop, tablet e mobile
✅ **SEO Otimizado** - Meta tags e estrutura HTML semântica
✅ **Performance** - Otimizado para carregamento rápido
✅ **Acessibilidade** - Cores e contraste adequados
✅ **Mobile-First** - Prioriza experiência em dispositivos móveis
✅ **Integração WhatsApp** - Botão direto para pedidos
✅ **Mapa Embarcado** - Localização no Google Maps
✅ **Animações Suaves** - Transições e efeitos visuais

## 📁 Estrutura de Arquivos

## 🚀 Implantação

O site está pronto para ser hospedado em:
- GitHub Pages (gratuito)
- Netlify (gratuito)
- Vercel (gratuito)
- Ou qualquer servidor web

### GitHub Pages

1. Acesse as configurações do repositório
2. Vá em "Pages"
3. Selecione "Deploy from a branch"
4. Escolha a branch "main"
5. Salve
